# Logo parser NSTAX

Taruh logo resmi di folder ini. Nama file (tanpa ekstensi) harus sama dengan `asset`
di `src/lib/parserBrands.tsx`. Format: svg, png, webp, jpg. Tidak perlu mengubah kode.

astana, fore, nsc, nasgor69, rotio, kai, hokben, kopken, fave, sams,
kland, pointcoffee, omala, omahpadhang, jambuluwuk, innatretes

Kategori (opsional, kalau ada logo khusus): cat-hotel, cat-resto, cat-prego, cat-kfood,
cat-cc, cat-glamping, cat-waterslide, dst. (lihat CATEGORY_BRANDS)

Jika file tidak ada / gagal dimuat, kartu otomatis menampilkan ikon fallback.
